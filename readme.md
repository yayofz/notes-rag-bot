# Notes RAG Bot

Локальный бот, который отвечает на вопросы по markdown-заметкам, опираясь только на их содержание. Он не выдумывает ответ, а находит релевантные куски текста и передаёт их языковой модели как контекст. Всё работает локально: без внешних API и без отправки данных наружу.

## Как это работает

```
заметки (.md) → куски по заголовкам → эмбеддинги → ChromaDB
                                                      ↓
вопрос → эмбеддинг → 3 ближайших куска → промпт → Ollama (qwen2.5:3b) → ответ
```

1. Заметка режется на куски по заголовкам (`##`, `###` и глубже).
2. Каждый кусок превращается в вектор (эмбеддинг) и сохраняется в векторную базу ChromaDB.
3. На вопрос ищутся 3 наиболее близких по смыслу куска.
4. Куски и вопрос отправляются в LLM (Ollama, модель `qwen2.5:3b`), которая работает полностью локально.
5. Ответ отдаётся через эндпоинт FastAPI.

## Стек

Python, FastAPI, ChromaDB, sentence-transformers (`paraphrase-multilingual-mpnet-base-v2`), Ollama.

## Требования

- Python 3
- Установленный [Ollama](https://ollama.com) с моделью `qwen2.5:3b`
- Свободное место на диске под модели: языковая модель и модель эмбеддингов скачиваются при первом запуске

## Запуск

```bash
pip install -r requirements.txt
ollama pull qwen2.5:3b
python3 main.py          # разовое наполнение базы из roadmap.md
uvicorn main:app --reload
```

После запуска доступна интерактивная документация: http://127.0.0.1:8000/docs. Там можно отправлять запросы к `/ask` мышкой.

В `roadmap.md` лежит пример заметок (учебный план по неделям). Можно заменить его своими markdown-файлами: чем яснее заголовки, тем лучше нарезка.

## Примеры вопросов

По примеру заметок `roadmap.md`:

- «Что нужно знать про Docker?»
- «Зачем нужен `.gitignore`?»
- «Какие темы в неделе про FastAPI?»

## Принятые решения

- **Нарезка по заголовкам, а не по числу слов.** Куски совпадают со смысловыми разделами заметки, а не обрываются посреди мысли.
- **Многоязычная модель эмбеддингов.** Заметки на русском, поэтому нужна модель, которая понимает русский.
- **Локальная LLM через Ollama.** Данные не уходят во внешние сервисы, использование не стоит денег.
- **Ответ только по найденному контексту.** Это снижает галлюцинации: бот опирается на заметки, а не на память модели.

## Известные ограничения

- Семантический поиск слабо различает числа (например, «неделя 1» и «неделя 5» могут путаться): эмбеддинги хорошо ловят тему, но не точные идентификаторы. Нужен гибридный поиск (метаданные плюс точная фильтрация), в этой версии не реализован.
- Мелкие куски иногда теряют контекст родительского раздела (например, кусок «Материалы» без привязки к тому, к какому этапу он относится).

## Что можно улучшить

- Гибридный поиск: семантика плюс фильтрация по метаданным (номер недели, раздел)
- Добавлять в каждый кусок заголовки родительских разделов
- Разделить индексацию и API на отдельные файлы (`ingest.py` и `app.py`)
- Оценка качества ответов на наборе тестовых вопросов
- Скриншоты и примеры ответов в README
- Docker-образ
