# RAG-бот по заметкам

Локальный бот, который отвечает на вопросы по markdown-заметкам, опираясь только на их реальное содержание — не выдумывает, а ищет релевантные куски текста и передаёт их в LLM как контекст.

## Как это работает

1. Заметка режется на куски по заголовкам (`##`, `###` и глубже)
2. Каждый кусок превращается в вектор (эмбеддинг) и сохраняется в векторную базу (ChromaDB)
3. На вопрос ищутся 3 наиболее релевантных по смыслу куска
4. Куски + вопрос отправляются в LLM (Ollama, модель `qwen2.5:3b`, работает полностью локально)
5. Ответ отдаётся через FastAPI-эндпоинт

## Стек

Python, FastAPI, ChromaDB, sentence-transformers (`paraphrase-multilingual-mpnet-base-v2`), Ollama

## Запуск

```bash
pip install -r requirements.txt
ollama pull qwen2.5:3b
python3 main.py       # разовое наполнение базы из roadmap.md
uvicorn main:app --reload
```

Дальше `http://127.0.0.1:8000/docs` — Swagger UI для тестирования `/ask`.

## Известные ограничения

- Семантический поиск слабо различает числа (например, "неделя 1" и "неделя 5" могут путаться) — эмбеддинги хорошо ловят тему, но не точные идентификаторы. Для этого нужен гибридный поиск (метаданные + точная фильтрация), не реализовано в этой версии.
- Мелкие куски текста иногда теряют контекст родительского раздела (например, кусок "Материалы" без явной привязки к тому, к какому этапу он относится).
