# Roadmap: от Python к backend и AI

Учебный план на 6 недель. Цель: собрать портфолио для роли Python backend / AI engineer и начать откликаться на вакансии.

## Неделя 1. База Python

Цель недели: уверенно писать небольшие скрипты и разбираться в чужом коде.

### Темы
- Строки, списки, словари, множества
- Функции, аргументы по умолчанию, `*args` и `**kwargs`
- Работа с файлами и JSON
- Обработка ошибок: `try/except`, свои исключения

### Практика
Написать функцию подсчёта частот слов и функцию нарезки текста на куски с перекрытием. Проверить краевые случаи: пустой текст, текст короче куска.

### Материалы
- Официальный tutorial по Python
- Книга «Изучаем Python»
- Задачи на сайте с упражнениями по основам

## Неделя 2. Git и окружение

Цель недели: хранить проекты в репозиториях и запускать их на любой машине.

### Темы
- Git: `init`, `add`, `commit`, `push`, ветки
- Виртуальные окружения и `requirements.txt`
- Файл `.gitignore`: что не должно попадать в репозиторий

### Практика
Залить два проекта на GitHub с понятными README. Проверить, что проект запускается после клонирования в чистую папку.

### Материалы
- Документация Git
- Руководство по `venv` в документации Python

## Неделя 3. FastAPI

Цель недели: обернуть свой код в HTTP API.

### Темы
- Эндпоинты GET и POST
- Модели запросов через Pydantic
- Коды ошибок: когда 400, а когда 500
- Автоматическая документация `/docs`

### Практика
Сделать эндпоинт `POST /chunks`, который принимает текст и параметры нарезки и возвращает куски. Добавить валидацию: размер куска больше нуля, перекрытие не отрицательное и меньше размера куска.

### Материалы
- Документация FastAPI
- Раздел про Pydantic в документации

## Неделя 4. Docker

Цель недели: запускать приложение одной командой в контейнере.

### Темы
- `Dockerfile`: `FROM`, `WORKDIR`, `COPY`, `RUN`, `CMD`
- Порядок слоёв и кэш сборки
- Проброс портов: `docker run -p 8000:8000`
- Файл `.dockerignore`

### Практика
Упаковать FastAPI-приложение в образ и запустить его. Внутри контейнера сервер должен слушать `0.0.0.0`, иначе до него не достучаться снаружи.

### Материалы
- Документация Docker, раздел Get started
- Статьи про оптимизацию образов

## Неделя 5. RAG

Цель недели: собрать бота, который отвечает по заметкам и не выдумывает.

### Темы
- Нарезка текста на куски по заголовкам
- Эмбеддинги: как текст превращается в вектор
- Векторная база ChromaDB и поиск ближайших кусков
- Промпт с контекстом: ответ только по найденным кускам
- Локальная модель через Ollama

### Практика
Проиндексировать этот файл, задать десять вопросов и проверить ответы глазами. Записать, где бот ошибается: например, путает «неделя 1» и «неделя 5».

### Материалы
- Документация ChromaDB
- Документация sentence-transformers
- Страница модели `qwen2.5:3b` в Ollama

## Неделя 6. Резюме и отклики

Цель недели: выйти на рынок.

### Темы
- Резюме на одну страницу под роль Python backend / AI engineer
- Оформление GitHub: закреплённые репозитории, README, профиль
- Подготовка к вопросам на собеседовании про свои проекты

### Практика
Разослать 10-15 откликов в неделю на hh.ru, Habr Карьере и в Telegram-каналах с вакансиями. После каждого собеседования записывать вопросы, на которые не смог ответить.

### Материалы
- Статьи про резюме для джуниоров
- Списки вопросов с собеседований по Python и FastAPI

## Правила работы

- Каждый день хотя бы час практики кодом, а не чтением.
- Проект считается готовым, когда у него есть README, запуск одной командой и пример вывода.
- Если застрял больше чем на час, написать вопрос и вернуться к нему на следующий день.
