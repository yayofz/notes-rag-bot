> [!note] Почему uv, а не poetry
> На 2026 год uv стал дефолтом для новых проектов — заменяет pip, venv, pyenv и большую часть функций Poetry, работает в разы быстрее. Poetry полезно узнать поверхностно (читать `pyproject.toml` с `[tool.poetry]`, запускать `poetry install`) — он ещё часто встречается в существующих/легаси проектах на фрилансе.

```bash
# uv — старт проекта
uv init myproject && cd myproject
uv add fastapi
uv add --dev pytest ruff
uv run pytest
```

> [!warning] Дисциплина AI-инструментов
> На каждом этапе ниже отдельно указано, где можно опираться на AI, а где — писать руками. Нарушение этого правила = деградация в "промптера без знаний".
